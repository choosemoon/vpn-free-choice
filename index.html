Help

安装提示

Windows 安装提示 ▾

1. 下载 .exe 安装包，双击运行

2. 如弹出 "Windows 已保护你的电脑" 提示，点击「更多信息」→「仍要运行」

3. 按向导完成安装即可

macOS 安装提示 ▾

1. 下载 .dmg 文件，双击打开

2. 将 Karing 图标拖入 Applications 文件夹

3. 首次运行时，前往「系统设置 → 安全性」点击「仍要打开」

4. 或在终端执行：xattr -cr /Applications/Karing.app

Android 安装提示 ▾

1. 下载 .apk 文件到手机

2. 安装前需在「设置」中允许安装未知来源应用

3. 不确定选哪个版本？优先选择 ARM64（2019年后的主流手机）
